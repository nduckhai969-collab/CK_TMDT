Mô tả chi tiết công việc

Doanh nghiệp chúng tôi cần tìm một lập trình viên Fullstack giàu kinh nghiệm để hoàn thiện dự án website bán hàng mỹ phẩm thiên nhiên.

Các hạng mục chính:
1. Lập trình Frontend từ thiết kế Figma đã được ban giám đốc duyệt (chuẩn Responsive máy tính và điện thoại).
2. Xây dựng trang danh mục sản phẩm, bộ lọc giá, thương hiệu và đánh giá sao.
3. Tích hợp giỏ hàng và cổng thanh toán trực tuyến qua VNPay & MoMo QR Code.
4. Tối ưu On-page SEO, schema markup sản phẩm và tốc độ tải trang đạt điểm Google Lighthouse > 90.
5. Hướng dẫn nhân viên quản trị thêm/sửa sản phẩm qua trang admin backend.

Kỹ năng yêu cầu bắt buộc

✓ ReactJS / Next.js ✓ NodeJS / RESTful API ✓ Cổng VNPay Chuẩn SEO On-page Responsive Mobile First
